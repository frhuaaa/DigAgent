# Current-contract examples

These are synthetic, validation-safe structural examples for implementation.
They are not real experiment evidence and must never be loaded into a formal
trajectory's Memory Bank. `EXP_000` demonstrates a baseline with no decision;
`EXP_001` demonstrates the mandatory Agent-driven RASS `6 + 4 = 10` bootstrap.

The numeric results are illustrative. Their purpose is to show file ownership,
exact result keys, three-decimal serialization, lineage, and test isolation.
There is deliberately no test artifact in this example tree.

Large production artifacts such as the full-width `valid_alpha.csv` and the
complete 158-factor RASS evidence table are intentionally represented only by
small structural excerpts here. Production output must still generate and
validate the complete artifacts required by `AGENTS.md`.
