# DiagAgent 四组实验失败与成功总结

> 研究者事后分析文档，整理日期：2026-09-25。
>
> 本文包含隔离测试集结果，只允许研究者在正式轨迹结束后审查。不得将本文或其中任何指标加入 CLEM、RASS、FAMA、RAPA、Contract Validator、Validation Gate、停止逻辑、accepted-state 更新或 Memory Bank 的输入。不得使用测试结果追溯修改既有 Gate 判定或选择实验。

## 1. 分析范围

本次汇总覆盖同期启动的四条 2024 轨迹：

```text
runs/csi1000_deepseek_c2c/2024/lstm/09250342
runs/csi1000_deepseek_o2o/2024/lstm/09250342
runs/csi500_deepseek_c2c/2024/lstm/09250342
runs/csi500_deepseek_o2o/2024/lstm/09250342
```

本文所说的“反转”不是指数涨跌方向反转，而是候选配置从 `agent_valid` 到 `test` 的相对排序或有效性发生反转。

## 2. 总结表

| 实验 | 最终 accepted experiment | Valid Sharpe（Round 0 → 最终） | Test Sharpe（Round 0 → 最终） | 事后判断 | 主要原因 |
|---|---:|---:|---:|---|---|
| CSI1000-C2C | EXP_010 | 验证期认可后续配置 | 2.179 → 1.295 | 失败 | RASS/FAMA 的验证期改善未泛化，配置排序在测试期反转 |
| CSI1000-O2O | EXP_006 | 验证期认可后续配置 | 1.016 → 0.695 | 失败 | 验证与测试配置排序严重错位；被验证拒绝的候选反而取得更高事后测试表现 |
| CSI500-C2C | EXP_009 | 0.780 → 0.836 | 1.344 → 1.609 | 成功 | RASS 不稳定候选被拦截并回退五因子；RAPA 提高换手惩罚的方向跨期一致 |
| CSI500-O2O | EXP_009 | 0.494 → 0.993 | 1.325 → 1.002 | 失败 | 八因子只在验证期有效；RankIC 改善没有转化为测试期组合收益，RAPA 无法补救上游 Alpha 退化 |

四组实验中，三组没有实现测试期提升，一组成功。共同的直接证据是验证期候选排序不能稳定代表测试期排序；但 CSI500-C2C 说明，当上游 Alpha 保持稳定且组合层方向具有跨期一致性时，系统能够取得正向结果。

## 3. CSI1000-C2C：失败

### 观察结果

- Round 0 测试 Sharpe：`2.179`。
- 最终 accepted EXP_010 测试 Sharpe：`1.295`。
- 后续 RASS/FAMA 配置在验证期获得接受，但测试期明显低于初始配置。

### 失败原因

1. **验证期自适应过拟合。** 多轮 RASS/FAMA 复用同一段 `agent_valid` 证据，后续决策逐渐适应该窗口中的偶然规律。
2. **新增因子或模型参数缺乏跨期稳定性。** 验证期提升并未在测试期保持，表现为候选相对排序反转。
3. **单 seed 训练噪声。** FAMA 候选之间的差距可能混入初始化、batch 顺序和优化噪声，使验证排序更不稳定。
4. **Gate 的信息边界。** Gate 只能合法地读取验证证据，因此无法提前识别未来测试区间的变化；这不是测试隔离错误。

### 结论

该轨迹没有证明 RASS/FAMA 的验证提升能够泛化。主要问题位于 Alpha/模型选择，而不是回测程序本身。

## 4. CSI1000-O2O：失败

### 观察结果

- Round 0 测试 Sharpe：`1.016`。
- 最终 accepted EXP_006 测试 Sharpe：`0.695`。
- 某个被 Validation Gate 拒绝的候选事后测试 Sharpe 约为 `1.811`，高于 accepted 状态和 Round 0。

### 失败原因

1. **验证与测试的配置排序严重反转。** 验证期判定更优的配置在测试期更差，而验证期拒绝的配置事后测试更好。
2. **O2O 对市场状态更敏感。** 隔夜信息、开盘跳空、开盘流动性、涨跌停约束和开盘滑点会放大跨阶段差异。
3. **验证窗口代表性不足。** `agent_valid` 中的最优方向不能代表随后测试区间的最优方向。
4. **不能用测试结果倒推重选。** 事后测试最好的拒绝候选只能用于研究诊断，不得追溯改写当时的接受结果。

### 结论

该轨迹的核心失败是 O2O 配置在验证期和测试期之间缺乏稳定排序，而不是 Gate 数值计算错误。

## 5. CSI500-C2C：成功，但成功来自组合层

### RASS 阶段

RASS 的三次完整新增因子尝试均未通过 Gate，系统随后按合同回退到初始五因子并冻结 Alpha。代表性候选包括：

- `STD30 + IMIN30 + CORR10`
- `QTLD30 + IMIN30 + STD20`
- 振幅类因子 `+ STD10 + MIN60`

这些候选在测试期也没有超过 Round 0，因此拒绝和回退避免了上游 Alpha 退化。

### RAPA 阶段

RAPA 找到稳定的换手惩罚方向：

| 实验 | turnover_penalty | Valid Sharpe | Test Sharpe | Gate/状态 |
|---|---:|---:|---:|---|
| EXP_000 | 1.0 | 0.780 | 1.344 | Round 0 |
| EXP_007 | 1.1 | 0.791 | 1.361 | 接受 |
| EXP_008 | 1.3 | 0.823 | 1.474 | 接受 |
| EXP_009 | 1.5 | 0.836 | 1.609 | 接受，最终状态 |
| EXP_010 | 1.5，并试调 risk_aversion | 0.835 | 1.604 | 拒绝并回滚到 EXP_009 |

最终相对 Round 0：

- Test Sharpe：`1.344 → 1.609`，增加 `0.265`，约 `19.7%`。
- Test annual return：`0.212 → 0.279`。
- Test max drawdown：`-0.102 → -0.085`。
- Test one-way turnover：`0.034 → 0.025`，下降约 `26.5%`。

### 成功原因和边界

1. RASS 没有强行接受不稳定的新因子。
2. 提高换手惩罚在验证期和测试期方向一致。
3. 更低换手减少了无效交易和成本，并改善回撤。
4. RAPA 复用预测，不引入重新训练噪声。

该结果证明的是**组合层优化成功**，不是 Alpha 或模型能力提高。测试期 Information Ratio 仍为负，因此按照当前“绝对 Sharpe 为主目标”的合同属于成功，但不能据此声称获得了稳定的基准超额能力。

## 6. CSI500-O2O：失败

### RASS 接受状态

EXP_002 接受了以下三个新增因子：

```text
QTLD30 + IMIN60 + STD20
```

验证期相对 Round 0：

- Sharpe：`0.494 → 0.972`。
- RankIC：`0.028 → 0.032`。

测试期相对 Round 0：

- Sharpe：`1.325 → 1.002`。
- Annual return：`0.237 → 0.130`。
- Max drawdown：`-0.093 → -0.122`。
- IC：`0.027 → 0.024`。
- RankIC：`0.036 → 0.040`。

### 失败原因

1. **RankIC 改善没有转化为组合收益。** 新因子改善了整体横截面排序，但没有改善最终 Top100/优化器关注区域中的经济收益。
2. **RASS 状态跨期失效。** 八因子组合在验证期大幅改善，却在测试期弱于初始五因子。
3. **RAPA 无法补救上游错误。** 后续换手和风险参数只是在已经退化的 Alpha 上微调，无法恢复 Round 0 表现。
4. **波动率 trade-off 可能与绝对 Sharpe 主目标存在张力。** 某些 Sharpe 较高的验证候选因波动率 guardrail 被拒绝，说明该 guardrail 值得在下一项独立研究中重新校准；不能依据测试结果在本轨迹中追溯修改。

### 结论

该轨迹是典型的验证期成功、测试期失败。主要责任位于 RASS 的跨期因子稳定性以及预测排序到组合收益的映射，而非 RAPA 搜索幅度不足。

## 7. 跨四组的共同失败机制

### 7.1 验证—测试排序不稳定

三个失败实验的共同直接证据为：

```text
agent_valid 中的候选优劣排序
!=
test 中的候选优劣排序
```

这比笼统地称为“市场涨跌反转”更准确。目前证据只能确认配置有效性发生跨期变化，不能单凭这些结果确定某一天或某一单因子突然反向。

### 7.2 同一验证窗口被多轮使用

即使每轮 intervention 很小，CLEM 和 specialists 反复观察同一 `agent_valid`，仍会逐渐对其产生自适应过拟合。有限轮次和 Memory Bank 可以减轻重复试验，但不能完全消除此问题。

### 7.3 IC/RankIC 与组合目标不完全一致

IC 和 RankIC 衡量预测排序；实际 Sharpe 还取决于：

- Top100 候选构造和已有持仓；
- 信号截面归一化；
- 风险模型和权重上限；
- 换手惩罚、交易成本和滑点；
- 涨跌停方向约束；
- 因子在组合真正持仓区域内的局部有效性。

所以 RankIC 提升不能单独证明组合层收益会提升。

### 7.4 单 seed 噪声

单 seed 会影响 checkpoint、FAMA 候选和模型输出的相对排序。三 seed ensemble 可以降低这类方差，但不能自动解决真实的跨市场阶段失效。

### 7.5 RAPA 的能力边界

RAPA 能够改善一个稳定 Alpha 的交易效率，如 CSI500-C2C；但当上游 Alpha 本身跨期失效时，调整 `turnover_penalty` 或 `risk_aversion` 通常只能小幅缓解，不能恢复预测能力。

## 8. 可用于论文的谨慎结论

建议表述为：

> DiagAgent 在 CSI500-C2C 中成功识别并拒绝了不稳定的 Alpha 干预，随后通过组合层的换手惩罚调整获得验证与测试方向一致的提升。这证明跨层诊断与回滚机制在部分设置下有效。另一方面，CSI1000-C2C、CSI1000-O2O 和 CSI500-O2O 暴露出同一验证窗口上的自适应过拟合以及跨市场阶段的配置排序反转，O2O 任务尤为明显。后续需要通过多 seed ensemble 和更稳健的时间序列验证降低选择方差，但不能使用隔离测试结果参与正式轨迹决策。

## 9. 后续分析边界

- 可以使用三 seed ensemble 降低模型训练噪声。
- 可以在新的、预先冻结的研究合同中比较滚动验证或多个连续 validation blocks。
- 可以单独研究 IC/RankIC 到组合收益的映射，以及波动率 guardrail 与绝对 Sharpe 主目标的协调方式。
- 不得用本文记录的测试结果修改、重判或恢复上述四条既有轨迹。
- 新规则必须在下一批正式实验启动前冻结，不能根据这四条测试结果逐项调参。
